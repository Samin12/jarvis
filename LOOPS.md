# Project loops

## Jarvis release conformance loop

Turns every promise in the Jarvis goal, plan, and README into evidence, then fixes and rechecks one bounded gap at a time until the downloadable first-run journey is proven or honestly blocked.

Prompt:

> Audit Jarvis against `docs/GOAL.md`, `docs/PLAN.md`, and `README.md`. Maintain a finite requirement ledger for download, ChatGPT sign-in, voice, connectors, Codex/computer actions, security, recovery states, CI, and packaging. Fix one confirmed gap per pass, preserve unrelated work, add regression coverage, then rerun lint, typecheck, tests, build, package, and clean-session UX checks. Stop only at a fully evidenced pass, an approval boundary, a blocker, or no measurable progress; never expose credentials or weaken checks.
